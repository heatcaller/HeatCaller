# Bug hunt over 15-21 Oct 2026 (run 22 Oct 2026)

Committed as `fc22c7a` with the requests made the same night (booth question
kept, State/Flag line removed, drawer label smear). `check.cmd`: 3,710 app
tests and 770 relay tests passed on 22 Oct 2026; the relay deployed the same
day.

## How it was run

- **Scope from git, not from file dates.** The repo is private and not
  reachable from the cloud session, so the week was rebuilt from the PC's
  own `.git`: the two packs plus the HEAD commit's trees, fetched object by
  object. File modification times were useless - the 17 Oct branch merge
  touched every file it carried. Base: `a9a799d9` (14 Oct, the last bug
  hunt). Result: 278 app files (+43.5k / -6.8k lines) and 21 relay files.
- **Fourteen reviewers**, one per area (after-race show, commentary
  settings UI, imaging and audio, commentary engine, On Air and Race
  Control, videos and recording, usage meters, show treatment, sponsors and
  the Team Principal, announcer and voice, nights and the relay client,
  two misc halves, the relay), each told to trace every finding to the
  code and drop anything it could not confirm.
- **Four fixers** on disjoint sets of files, then **one independent
  reviewer** over the whole fix diff looking for compile errors (there is no
  .NET SDK in the cloud session) and wrong fixes. It found four logic
  problems, all fixed before anything was written to the PC.
- **What still got through** the read-only review, and why it matters:
  - CS0102: a new `AnnouncementService.VoiceSignature` property collided
    with a private static method of the same name in another partial file.
    The reviewer grepped the members it saw used, not the names it saw added.
  - Two "fixes" broke tests that pin deliberate rules: a lap of a minute or
    more is read plainly (`RaceNumbersTests`), and a DNF anywhere leaves the
    Team Principal Defensive even on a win (`PrincipalStanceTests`). Both
    were reverted. **Grep the tests for a behaviour before changing it.**

## Fixed (the ones a club would notice)

- **Sponsor reads with AI commentary off never went out at all** -
  `FeedTheSponsorsOnly` never told the director a race had started or
  finished, and `ReadsBelongHere` needs that.
- **Unticking "Read at the end of an ad break" still read in the break**
  (a fallback to the between-races placement). Removed.
- **A sponsor's copy read in parts counted as several reads** -
  continuation parts (`SponsorRead.Continuation`) count nothing more.
- **Existing installs kept reading between races** because the old default
  was saved in `sponsors.json` - one-time migration
  (`SegmentsDefaultReviewed`).
- **The booth's first question was trimmed away** (`KeepTheQuestion`).
- **The relay's usage route reported an unreadable count as "0 used"** -
  `known:false` now, and the app keeps its last figure; a figure past its
  reset shows unknown.
- **An aborted video download hung the relay's handler for good** - the
  write loop wakes on `close`; uploads capped two in flight.
- Podium videos: the cut could lose the finish (now cut round the flag);
  pruning never deleted mp4s (and dropped the night marker anyway, so they
  were never retried); a late upload from an earlier race could show its QR
  over the next race (generation check); every driver's mp3 waited behind
  every video render and upload (two loops now); release calls had no
  captions with listen-along off.
- On Air: driver introductions only came with the round intro (race intros
  off, mains-only on a heat, or a failed intro meant none); Yellow/Red
  during a demo's On Air called it off; a demo moving itself cancelled a
  new demo's On Air; voiced-ahead takes could play in an old voice.
- After the flag: the result read ate the pause; Skip/Hold lost the
  achievements held back for the recap; a practice save closed the
  write-ahead gate for 45 s; stop messages blamed "the next race" after a
  Skip; Lap times only still read the result.
- Leaderboard drawer: double-click under an open drawer missed the lap
  breakdown; captions painted over the row above mid-slide (`TextRenderer`
  ignores the Graphics clip).
- Audio: a crowd held silent by On Air made every preview silent (the
  preview now closes it and opens its own); a bed started mid-line came up
  unducked; mute missed imaging already playing (`BroadcastImaging.StopAll`).
- The long ElevenLabs limit applies to lines rendered ahead only; voice
  listing has its own 30 s.
- Smaller: co-host card greyed while it was asking every interview; Delete
  Race Day overcounted the achievements it would take back; handicaps lost
  every Quick Race session; setups with a blank id were dropped on the next
  save; club notes could miss a note for good; the nights close logged
  every 30 s all evening; listen-along logged "working again" while down;
  the public vote ballot ignored "abbreviate names"; the show card said the
  club's music didn't play when it did; a failed sponsor video preview said
  "End of video".

## Left open, and why

Each was confirmed but not fixed because it could not be done safely
without a build at the time.

| What | Why it was left |
|---|---|
| A battle held by the pacing gap is offered again every crossing (padding "held" and the lost-lines list) | The voice queue can't yet tell a pacing hold from a drop; needs plumbing through `EnqueueVoiceWork` |
| A recap render already under way isn't cancelled when the next race is called (a slot for up to 150 s) | Needs a `CancellationToken` through `PrepareReminderAsync` / `RenderLineAsync` / the synthesis gate |
| "Presented by" counts are lost on a restart | `SponsoredMomentGate` is memory only; persist like `SponsorRotation.Save` |
| Post and last-word timing start before a reopening device plays | Needs a "first read" signal from `AudioBus` |
| Relay vote ids stop matching if the check-in key changes mid-poll | Read the key once per pass and keep the old map, or send a new ballot id |
| LAN pages lose achievements for 5 minutes after one locked read | Shorter retry for an unreadable (not unparseable) load |
| Track Designer Cut + Paste of part of the racing line loses those points | Leave route points in place on a partial cut, or warn |
| Built-in model cold load ignores the caller's timeout | Shared load task awaited with `WaitAsync(ct)` |
| The stop-set throw and the break ask "is there a break?" separately | Decide once, pass it to all four places |
| `CommentaryLowestTier` has no control | Nothing writes it |
| A segment whose model call throws doesn't give the sponsor ration back | Wrap in try/catch and `GiveBack` |
| Relay: the race page has no limiter; every range re-reads up to 120 meta files; club delete doesn't take the videos lock | Cost, not correctness; theoretical race |
