# Keyboard shortcuts

These are all the keyboard shortcuts in HeatCaller. The most useful ones are the flag keys on **Race Control**, which let you run a race without aiming the mouse at a small button.

Press <kbd>?</kbd> at any time you're not typing in a box to see a sheet of the main shortcuts in the app itself, titled **Keyboard shortcuts**. Any key (other than <kbd>Shift</kbd>, <kbd>Ctrl</kbd> or <kbd>Alt</kbd> on their own) or a click closes it. Pointing at a button on **Race Control** also shows its shortcut.

## Race Control

These work while the **Race Control** page is showing, and throughout Race Mode.

| Key | Does the same as |
|---|---|
| <kbd>0</kbd> | **On Air** (it has no button on the flag row). Hold it for a second while On Air runs to skip straight to staging; let go early and nothing happens. Either <kbd>0</kbd>, the top row's or the keypad's. |
| <kbd>F1</kbd> | Starts the race the normal way: through **On Air** when **Start:** is set to **On Air**, otherwise **Stage**. Pressed while On Air runs it does nothing except remind you, in the log, to hold <kbd>0</kbd> to skip. The **Stage** button itself always stages straight away. |
| <kbd>F2</kbd> | **Countdown** |
| <kbd>F3</kbd> | **Green**. It also resumes the race after a yellow or red. |
| <kbd>F4</kbd> | **Yellow** |
| <kbd>F5</kbd> | **Red** |
| <kbd>F6</kbd> | **Checkered** |
| <kbd>F7</kbd> | **Reset**. If a race is staging, counting down or running, it asks first ("A race is under way. Reset it? (Undo can still bring it back.)"). |
| <kbd>F8</kbd> | **Quick Race** |
| <kbd>F9</kbd> | **Skip**, between races: skips the part of the recap show or the line on air. Holding the button ends the whole recap show; the key never does. |
| <kbd>F10</kbd> | **Hold Talk** / **Resume Talk**: nothing is said between races until you press it again. |
| <kbd>F12</kbd> | **Call Up**: calls up the next race now. |
| <kbd>H</kbd> | **Hold** / **Resume** on the Next Up bar: holds Auto start's count to the next race, and carries it on again. See [Auto start between races](../race-control/running-a-race.md#auto-start-between-races). |
| <kbd>N</kbd> | **Start now**, from the **Hold** button's right-click menu: starts the next race without waiting for the count. |
| <kbd>S</kbd> | **Play again** on the On Air bar: plays a recent line again. See [Play a line again](../race-control/running-a-race.md#play-a-line-again). |
| <kbd>B</kbd> | **Big Screen** |
| <kbd>R</kbd> | **Pre-race check** |
| <kbd>A</kbd> | **Announcer Screen** |

Each key does what clicking its button does (except <kbd>F1</kbd>, described above, and <kbd>F7</kbd>, which asks first while a race is under way; the button doesn't), including Stage following on to Countdown and Green by itself when the race format has that turned on. See [Running a race](../race-control/running-a-race.md).

The **Red**, **Checkered** and **Reset** buttons have to be pressed and held for about a second, so a stray click can't stop or end a race. Their keys, <kbd>F5</kbd>, <kbd>F6</kbd> and <kbd>F7</kbd>, act on a single press. See [Press and hold](../race-control/running-a-race.md#press-and-hold).

**Only the bare key counts.** If you hold <kbd>Alt</kbd>, <kbd>Ctrl</kbd> or <kbd>Shift</kbd>, the F-keys do nothing. For example, <kbd>Alt</kbd>+<kbd>F4</kbd> closes the window as usual and never throws a yellow flag on its way out.

<kbd>H</kbd> and <kbd>N</kbd> only do something while Auto start is counting down to a race. Otherwise the Race Control log says why nothing happened. They're letters rather than F-keys because every F-key is already taken.

The F-keys work even while you're typing in a box on the page. The letter keys and <kbd>0</kbd> don't: while a text box, a number box, a time box, a drop-down list or a grid cell you're editing has the focus, a letter is typing, not a shortcut. None of them work on any other page, or while a dialog is open. Two windows pass the F-keys on to Race Control: the **Broadcast** window takes <kbd>F1</kbd> to <kbd>F10</kbd> and <kbd>F12</kbd>, and a driver's lap breakdown window takes <kbd>F1</kbd> to <kbd>F8</kbd>, so you can throw a flag without clicking back to the main window first.

!!! tip "Flag buttons and the Space bar"
    After you click a flag button, the focus moves off it. So a stray <kbd>Space</kbd> or <kbd>Enter</kbd> can't press the same flag again, and restart a race that's already running.

!!! note "Race Mode and the flag keys"
    <kbd>F11</kbd> always switches to the Race Control page and selects **Race Control** in the sidebar, even if you press it on another page. The flag keys work straight away in Race Mode, and still work when you leave it.

!!! note "Desk View turns the shortcuts off"
    While the laptop is locked with **Desk View...** (on **Race Day → Who's Racing**), none of these shortcuts work: not the function keys, not the letters, not <kbd>F11</kbd>. Typing still works, and so do <kbd>Ctrl</kbd>+<kbd>C</kbd>, <kbd>Ctrl</kbd>+<kbd>V</kbd>, <kbd>Ctrl</kbd>+<kbd>X</kbd>, <kbd>Ctrl</kbd>+<kbd>A</kbd> and <kbd>Ctrl</kbd>+<kbd>Z</kbd> in a box (there <kbd>Ctrl</kbd>+<kbd>Z</kbd> undoes your typing, never the app's last change). <kbd>AltGr</kbd> still types characters such as @. See [Events and entries](../race-day/events-and-entries.md#self-check-in-poster).

## The selected driver

Click a driver on the Race Control leaderboard first. These work while **Race Control** is showing, and not while you're typing in a box.

| Key | What it does |
|---|---|
| <kbd>+</kbd> | Adds a lap (same as **+1 Lap**). The <kbd>=</kbd> key and the number-pad <kbd>+</kbd> work too. |
| <kbd>-</kbd> | Removes a lap (same as **-1 Lap**). |
| <kbd>P</kbd> | Adds a 5-second penalty. |
| <kbd>Shift</kbd>+<kbd>P</kbd> | Adds a 10-second penalty. |
| <kbd>C</kbd> | Clears the driver's penalties. |
| <kbd>W</kbd> | Opens the warning menu at the driver's row. Then <kbd>1</kbd> to <kbd>7</kbd> picks a reason, or <kbd>0</kbd> lets you type one. |
| <kbd>Shift</kbd>+<kbd>W</kbd> | Takes back the driver's last warning. |
| <kbd>L</kbd> | Opens the driver's lap breakdown. |
| <kbd>E</kbd> | Edits the driver. |

If no driver is selected, nothing happens and the Race Control log says why. See [Corrections and recovery](../race-control/corrections-and-recovery.md).

With the mouse:

- **Ctrl+click** or **right-click** erases with any tool.
- **Ctrl-drag** with the Floor tool takes floor tiles back off.
- With the Route tool, right-click removes a point.
- Dragging with the **middle button**, or with **Shift** and the right button, moves the view, like <kbd>Space</kbd> + drag.
- The **mouse wheel** zooms. With the Photo tool, it resizes the traced photo instead.
- Clicking the zoom readout in the corner of the plan goes back to 100%.

### Picking part of a plan up

Take the **Select** tool (<kbd>8</kbd>) and drag a box round part of the plan. Everything the box covers is picked up. Each tile brings the rail or turn bolted to it, so the rails round the edge of a block of tiles come with it, and a rail on the box's edge bolted to a tile outside it stays with that tile.

Then:

| Key | What it does |
|---|---|
| Arrow keys | Nudges what's picked one tile |
| <kbd>]</kbd> | Turns it a quarter clockwise, where it stands |
| <kbd>[</kbd> | Turns it a quarter the other way |
| <kbd>Delete</kbd> or <kbd>Backspace</kbd> | Takes it off the plan |
| <kbd>Esc</kbd> | Drops it - nothing is picked any more |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Picks up the whole plan |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Copies it |
| <kbd>Ctrl</kbd>+<kbd>X</kbd> | Cuts it |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | Puts a copy down where the pointer is |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> | Duplicates it, one tile along |

These need the plan to have the focus, like the tool keys. **Turn**, **Flip across**, **Flip down**, **Duplicate** and **Remove** on the toolbar do the same things, and are grayed out while nothing is picked.

With the mouse:

- **Drag inside** what's picked to move it.
- **Shift-drag** another box to add to what's picked - or, over something already picked, to take it back out.
- **Click** bare floor to drop the selection.
- **Drag a square handle** on the right or bottom edge to make the plan longer or shorter there, by whole tiles (see [Stretch part of the plan](../race-day/track-designer.md#stretch-part-of-the-plan)).

A turn or a mirror keeps the top-left corner of the box where it is, so turning a layout never slides it off the floor you had it lined up with. One drag, nudge, turn or mirror is one press of <kbd>Ctrl</kbd>+<kbd>Z</kbd>.

!!! note "What a move lands on, it replaces"
    A plan holds one tile, one rail and one marking per place. So if you move or paste something onto part of the plan that's already occupied, what was underneath is taken off and what you moved stays. <kbd>Ctrl</kbd>+<kbd>Z</kbd> puts it all back.

!!! note "The racing line comes too"
    Route points inside the box are picked up with everything else, so <kbd>Ctrl</kbd>+<kbd>A</kbd> and then an arrow key moves the whole plan, racing line included. Picking up only part of the line moves only those points, which bends it - that's deliberate, but it's easy to do by accident on a half-covered layout.

!!! tip "Picking up a plan changes nothing by itself"
    Dragging a box is only looking, so it takes no undo step. <kbd>Ctrl</kbd>+<kbd>Z</kbd> straight after a marquee takes back your last *edit*, not your last look.
