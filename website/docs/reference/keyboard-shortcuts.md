# Keyboard shortcuts

These are all the keyboard shortcuts in HeatCaller. The most useful ones are the flag keys on **Race Control**, which let you run a race without aiming the mouse at a small button.

Press <kbd>?</kbd> at any time you're not typing in a box to see a sheet of the main shortcuts in the app itself. Any key or a click closes it. Pointing at a button on **Race Control** also shows its shortcut.

## Race Control

These work while the **Race Control** page is showing, and throughout Race Mode.

| Key | Does the same as |
|---|---|
| <kbd>0</kbd> | **On Air** (it has no button on the flag row). Hold it for a second while On Air runs to skip straight to staging; let go early and nothing happens. Either <kbd>0</kbd>, the top row's or the keypad's. |
| <kbd>F1</kbd> | Starts the race the normal way: through **On Air** when **Start races On Air** is ticked, otherwise **Stage**. Pressed while On Air runs it does nothing except remind you, in the log, to hold <kbd>0</kbd> to skip. The **Stage** button itself always stages straight away. |
| <kbd>F2</kbd> | **Countdown** |
| <kbd>F3</kbd> | **Green**. It also resumes the race after a yellow or red. |
| <kbd>F4</kbd> | **Yellow** |
| <kbd>F5</kbd> | **Red** |
| <kbd>F6</kbd> | **Checkered** |
| <kbd>F7</kbd> | **Reset**. If a race is staging, counting down or running, it asks first ("A race is under way. Reset it? (Undo can still bring it back.)"). |
| <kbd>F8</kbd> | **Quick Race** |
| <kbd>F9</kbd> | **Skip**, between races: skips the part of the recap show or the line on air. Holding the button ends the whole recap show; the key never does. |
| <kbd>F10</kbd> | **Hold Talk** / **Resume Talk**: nothing is said between races until you press it again. |
| <kbd>F12</kbd> | **Call Up**: calls up the next race now. |
| <kbd>B</kbd> | **Big Screen** |
| <kbd>R</kbd> | **Pre-race check** |
| <kbd>A</kbd> | **Announcer Screen** |

Each key does what clicking its button does (except <kbd>F1</kbd>, described above, and <kbd>F7</kbd>, which asks first while a race is under way; the button doesn't), including the automatic follow-on from Stage to Countdown to Green when the race format has that turned on. See [Running a race](../race-control/running-a-race.md).

**Only the bare key counts.** If you hold <kbd>Alt</kbd>, <kbd>Ctrl</kbd> or <kbd>Shift</kbd>, the F-keys do nothing. For example, <kbd>Alt</kbd>+<kbd>F4</kbd> closes the window as usual and never throws a yellow flag on its way out.

The F-keys work even while you're typing in a box on the page. The letter keys and <kbd>0</kbd> don't: while a text box, a number box, a drop-down list or a grid cell you're editing has the focus, a letter is typing, not a shortcut. None of them work on any other page, or while a dialog is open.

!!! tip "Flag buttons and the Space bar"
    After you click a flag button, the focus moves off it. So a stray <kbd>Space</kbd> or <kbd>Enter</kbd> can't press the same flag again, and restart a race that's already running.

!!! note "Race Mode and the flag keys"
    <kbd>F11</kbd> always switches to the Race Control page and selects **Race Control** in the sidebar, even if you press it on another page. The flag keys work straight away in Race Mode, and still work when you leave it.

## The selected driver

Click a driver on the Race Control leaderboard first. These work while **Race Control** is showing, and not while you're typing in a box.

| Key | What it does |
|---|---|
| <kbd>+</kbd> | Adds a lap (same as **+1 Lap**). The <kbd>=</kbd> key and the number-pad <kbd>+</kbd> work too. |
| <kbd>-</kbd> | Removes a lap (same as **-1 Lap**). |
| <kbd>P</kbd> | Adds a 5-second penalty. |
| <kbd>Shift</kbd>+<kbd>P</kbd> | Adds a 10-second penalty. |
| <kbd>C</kbd> | Clears the driver's penalties. |
| <kbd>W</kbd> | Opens the warning menu at the driver's row. Then <kbd>1</kbd> to <kbd>7</kbd> picks a reason, or <kbd>0</kbd> lets you type one. |
| <kbd>Shift</kbd>+<kbd>W</kbd> | Takes back the driver's last warning. |
| <kbd>L</kbd> | Opens the driver's lap breakdown. |
| <kbd>E</kbd> | Edits the driver. |

If no driver is selected, nothing happens and the Race Control log says why. See [Corrections and recovery](../race-control/corrections-and-recovery.md).

## Anywhere in the app

| Key | What it does |
|---|---|
| <kbd>?</kbd> | Shows the keyboard shortcuts sheet. |
| <kbd>Shift</kbd>+<kbd>S</kbd> | Opens the Set Up Tonight wizard, which sets up a race night step by step. See [The Set Up Tonight wizard](../race-day/events-and-entries.md#the-set-up-tonight-wizard). |
| <kbd>Shift</kbd>+<kbd>T</kbd> | Starts the app tour, a short look around the main pages. See [The app tour](../getting-started/install.md#the-app-tour). Not in Race Mode. |
| <kbd>M</kbd> | Mutes or unmutes all sound, the same as the mute button at the bottom of the sidebar. |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Undo, the same as the **Undo** button at the bottom of the sidebar. In a text box, it undoes your typing instead. |
| <kbd>Ctrl</kbd>+<kbd>1</kbd> to <kbd>Ctrl</kbd>+<kbd>9</kbd> | Opens that page in the sidebar, counting from the top (hidden pages are skipped). Not in Race Mode. |
| <kbd>Ctrl</kbd>+<kbd>F</kbd> | Puts the cursor in the **Search pages...** box. If the sidebar is down to its icons, it opens again first. Not in Race Mode. |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> | Narrows the sidebar to just its icons, and opens it again. The chevron beside the **Search pages...** box does the same. How you leave it is remembered. Not in Race Mode, which has no sidebar. |
| <kbd>F11</kbd> | Turns **Race Mode** on or off. Race Mode is full screen with no sidebar, showing only the **Race Control** page. Turning it on also selects **Race Control** in the sidebar. |
| <kbd>Esc</kbd> | Leaves Race Mode (only while it's on, and not while you're editing a grid cell or a list is open). |
| <kbd>Ctrl</kbd>+<kbd>+</kbd> | Makes all text in the app bigger, 10% at a time (up to 200%). |
| <kbd>Ctrl</kbd>+<kbd>-</kbd> | Makes all text smaller, 10% at a time (down to 85%). |
| <kbd>Ctrl</kbd>+<kbd>0</kbd> | Puts the text size back to 100%. |

<kbd>?</kbd>, <kbd>Shift</kbd>+<kbd>S</kbd>, <kbd>Shift</kbd>+<kbd>T</kbd> and <kbd>M</kbd> are ignored while you're typing in a box. The <kbd>Ctrl</kbd> keys work on every page, whatever has the focus. The number-pad <kbd>+</kbd>, <kbd>-</kbd> and <kbd>0</kbd> keys work too, and so do the number-pad digits for <kbd>Ctrl</kbd>+<kbd>1</kbd> to <kbd>9</kbd>. The text size is remembered between sessions.

## Big Screen

| Key | What it does |
|---|---|
| <kbd>F11</kbd> | Turns full screen on or off. |
| <kbd>M</kbd> | Shows or hides the track map, when the layout has a plan. See [Track map](../screens/big-screen.md#track-map). |

The Big Screen shows a reminder of these keys. Click the Big Screen window first so it has the focus. See [Big Screen](../screens/big-screen.md).

## Dialogs

| Key | What it does |
|---|---|
| <kbd>Enter</kbd> | Presses the dialog's main button, usually **Save**, **OK** or **Close**. |
| <kbd>Esc</kbd> | Cancels or closes the dialog. On a Yes/No question, <kbd>Esc</kbd> answers **No**. |

## Race Day → Who's Racing: scanning QR check-ins

Click the box in the **Scan to Check In** card, then scan a driver's QR check-in. A USB barcode scanner types the code and then presses <kbd>Enter</kbd>, which checks the driver in. You can also type a code and press <kbd>Enter</kbd> yourself. See [Events and entries](../race-day/events-and-entries.md).

The number keys, <kbd>L</kbd>, <kbd>C</kbd>, <kbd>T</kbd>, <kbd>V</kbd>, <kbd>R</kbd>, <kbd>F</kbd>, <kbd>G</kbd>, <kbd>P</kbd> and <kbd>Space</kbd> only work while the plan has the focus, so they never get in the way of typing a track name. Click the plan first if they don't respond. <kbd>Ctrl</kbd>+<kbd>Z</kbd> and <kbd>Ctrl</kbd>+<kbd>Y</kbd> work anywhere in the Track Designer window.

With the mouse:

- **Ctrl+click** or **right-click** erases with any tool.
- **Ctrl-drag** with the Floor tool takes floor tiles back off.
- With the Route tool, right-click removes a point.
- The **mouse wheel** zooms. With the Photo tool, it resizes the traced photo instead.

### Picking part of a plan up

Take the **Select** tool (<kbd>8</kbd>) and drag a box round part of the plan. Everything the box covers is picked up, and because the box snaps out to whole tiles, the rails round the edge of a block of tiles come with it rather than being left behind.

Then:

| Key | What it does |
|---|---|
| Arrow keys | Nudges what's picked one tile |
| <kbd>]</kbd> | Turns it a quarter clockwise, where it stands |
| <kbd>[</kbd> | Turns it a quarter the other way |
| <kbd>Delete</kbd> | Takes it off the plan |
| <kbd>Esc</kbd> | Drops it - nothing is picked any more |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Picks up the whole plan |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Copies it |
| <kbd>Ctrl</kbd>+<kbd>X</kbd> | Cuts it |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | Puts a copy down where the pointer is |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> | Duplicates it, one tile along |

These need the plan to have the focus, like the tool keys. **Turn**, **Flip across**, **Flip down**, **Duplicate** and **Remove** on the toolbar do the same things, and are grayed out while nothing is picked.

With the mouse:

- **Drag inside** what's picked to move it.
- **Shift-drag** another box to add to what's picked - or, over something already picked, to take it back out.
- **Click** bare floor to drop the selection.
- **Drag a square handle** on the right or bottom edge to make the plan longer or shorter there, by whole tiles (see [Stretch part of the plan](../race-day/track-designer.md#stretch-part-of-the-plan)).

A turn or a mirror keeps the top-left corner of the box where it is, so turning a layout never slides it off the floor you had it lined up with. One drag, nudge, turn or mirror is one press of <kbd>Ctrl</kbd>+<kbd>Z</kbd>.

!!! note "What a move lands on, it replaces"
    A plan holds one tile, one rail and one marking per place. So if you move or paste something onto part of the plan that's already occupied, what was underneath is taken off and what you moved stays. <kbd>Ctrl</kbd>+<kbd>Z</kbd> puts it all back.

!!! note "The racing line comes too"
    Route points inside the box are picked up with everything else, so <kbd>Ctrl</kbd>+<kbd>A</kbd> and then an arrow key moves the whole plan, racing line included. Picking up only part of the line moves only those points, which bends it - that's deliberate, but it's easy to do by accident on a half-covered layout.

!!! tip "Picking up a plan changes nothing by itself"
    Dragging a box is only looking, so it takes no undo step. <kbd>Ctrl</kbd>+<kbd>Z</kbd> straight after a marquee takes back your last *edit*, not your last look.

## Mixer faders

On **Sounds → Mixer**, click a fader to give it the focus, then:

| Key | What it does |
|---|---|
| <kbd>↑</kbd> / <kbd>↓</kbd> | Up or down 1% |
| <kbd>Page Up</kbd> / <kbd>Page Down</kbd> | Up or down 10% |
| <kbd>Home</kbd> | 100% |
| <kbd>End</kbd> | 0% |

The mouse wheel moves a fader by 1% too.

## Time boxes

In a time box, such as the **Time:** box when you add or edit a line in the **Timetable** window, **First race at:** on **Race Day → Setup**, or **First race at:** in **Fill in the times**:

| Key | What it does |
|---|---|
| <kbd>←</kbd> / <kbd>→</kbd> | Moves between hours, minutes and AM/PM |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Changes the selected part |
| Digits | Types the value directly |
| <kbd>A</kbd> / <kbd>P</kbd> | Sets AM or PM (12-hour time only) |
