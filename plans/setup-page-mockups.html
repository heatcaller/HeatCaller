Race Day › Setup · design review · 14 Nov 2026

Setup, rebuilt around templates

Four directions for the Setup page. All four take New Race Day off the page and make picking a template the way a night starts. Each one shows the page on a Saturday morning, before anything has been started.

What's wrong with the page now

Setup is one long scroll with three cards: Which race day, About the day and Building the program. Starting a night happens in four places: New Race Day, Set Up Tonight…, the Start Tonight window, and a templates row with five buttons, which sits halfway down the page between "Next night on phones" and Notes. The Start Tonight window is already a template picker (Like last time, each template, Something different), but you only see it after pressing a button.

4ways onto the same Start Tonight window from this page
32rows and ticks in one scroll, with nothing collapsed
7of them say "For every night, not just this one" and save to club settings
5buttons in the Templates row: Start, When…, Save This Day As…, Delete, plus the picker

Start from a template

Picking a template is how a night starts. "Like last time" and "Something different" are listed as templates too, so all the options sit in one place.

Keep tonight and the club apart

The seven club-wide ticks move out of tonight's sheet. Changing them shouldn't feel like editing one night.

Edit templates directly

Today a template can only be made by saving a day. NightTemplate has the same fields as a day, so the day editor can edit a template too.

Setup gets three tabs of its own: Templates, Tonight and Club rules. Templates is where the page opens when no night is running. Each template is a card you can read at a glance, and tonight's template sits above the rest with a Start button.

Something different…

Pick the kind of night and the classes. Everything else comes from your last race day.

Start a blank night
  1. 1Three tabs instead of one scroll. Templates is the start. Tonight is the day sheet that exists now, trimmed to this night's fields and grouped. Club rules holds the seven "every night" ticks. Once a night is open, Setup opens on Tonight.
  2. 2Tonight's template comes first. This is NightTemplates.ForDay, which Next Steps already uses. The big button starts the night with no extra window. Walk me through it… is the Set Up Tonight wizard, kept as a secondary option.
  1. 3Each card shows everything that template does: classes, heats, times, breaks, fees and which nights it's for. You no longer need a drop-down to read a template. The ⋯ menu holds When…, Duplicate, Rename and Delete.
  2. 4"Like last time" is a card too. It shows how the last night actually went and how it differed from its template, so Save as template makes sense right there.
  3. 5Something different replaces the two questions in the Start Tonight window. It's the only card a club sees on its first night.

Gets right

  • Starting a night takes one press, on the page you're already on.
  • You can compare templates without opening each one.
  • Club-wide rules stop looking like tonight's settings.
  • Cards reflow to two columns at large text sizes or 1280×720.

Costs

  • One more level of tabs inside Race Day › Setup.
  • The Tonight tab still needs its own redesign, though grouping is most of it.
  • A club with eight or more templates needs a search or a "pinned" row.

A list on the left holds tonight, your templates and recent nights. On the right, one editor works for whichever you pick. Templates are edited the same way a night is, and a forecast at the bottom shows whether the night fits before you start it.

Gets right

Costs

  • Two columns get tight at 1280×720 with large text, so the list needs to collapse to a drop-down.
  • Editing a template and editing tonight look alike, so the TEMPLATE / TONIGHT label has to be clear.
  • Club-wide ticks still need somewhere to live, such as a "Club rules" entry at the bottom of the list.

Tonight, One Press

The page changes with the night. Before a night starts, it's one large card with tonight's template already chosen and the others in a row underneath. Once the night starts, the page turns into a short paragraph about the night, and each underlined value can be clicked to change it. The Set Up Tonight wizard goes away, and the card does its job instead.

  1. 1One choice with a sensible default. On a night with a template set, the page opens with everything ready, so starting is one press. Change something first… opens the full editor before the night starts.
  2. 2The other templates are a row of options, the same choices the Start Tonight window offers now, shown on the page. Picking one rewrites the card above.
  3. 3The wizard's job, shown on the page. Set Up Tonight used to walk you through these steps. Now they're a list of what comes next, and each step links to the tab where you do it.
  1. 4Tonight as a paragraph. Each underlined value opens a small editor in place. A value with a problem is shown in amber, like the out-by time here. The full grid is still under Fine-tune every setting… for the rare fields.
  2. 5Club rules as a side card, showing what they are. Editing them goes to Settings, where club-wide things belong.

Gets right

  • The fastest start of the four for a club with a regular schedule.
  • The paragraph is easy to check over a cup of coffee before the gates open.
  • Removes the Set Up Tonight wizard and its rail, footer and layout audit.

Costs

  • The paragraph format is new to the app and has to work at every text size and wrap cleanly.
  • Rare fields (share-under, races off, between-race talk) end up one click further away.
  • Managing templates needs its own screen, behind "Manage templates ›".

My recommendation

Build A and borrow two things from B: the forecast line goes in the tonight banner ("16:20 projected, 40 min to spare"), and Edit on a card opens the same grouped editor that the Tonight tab uses. That gives a one-press start, templates you can read at a glance, and club-wide rules on their own tab, without a new layout that has to survive 1280×720. C's step list could later become Next Steps' empty state, and D's planner could be added to the existing Calendar tab instead of Setup.

Where today's fields go in A

Every row on the current page, mapped to its new place. Nothing is removed. Two dialogs are replaced by controls on the page.
