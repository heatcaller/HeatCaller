The Setup card, as the PC sheet

The sheet's sections and fields as the laptop's Garage holds them, in the same order and words, as text with an input box or dropdown on each row. There are no pictures. Every control below works: change a value and the change marker, the section count and the Save button all update.

Each field type

  • Choice: dropdown, "—" first, then the sheet's options in order
  • Number: number box with its unit inside (mm, °, pcs)
  • Text: one-line box; Notes gets a larger box
  • Yes/No: dropdown — / Yes / No
  • Multi-pick: dropdown showing "2 picked"; opens a ticked list

What changed

  • An accent bar and "was …" on every field you change
  • Each section's heading counts what's set and what changed
  • Save says what it will do: "Save setup · 3 changes"
